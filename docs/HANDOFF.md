## Run

```bash
npm install
npm run dev
npm run check                 # format + content + lint + typecheck + build + static assert
```

Production: set `NEXT_PUBLIC_SITE_URL` (and optionally `NEXT_PUBLIC_ALLOW_INDEXING=true`) before
`npm run build`; `NEXT_PUBLIC_*` is inlined at build time. See `.env.example` and `Dockerfile`.

## Current architecture

- 44 static routes. Metadata comes from each route's JSON via `buildPageMetadata`.
- `src/content/tano/routes.ts` is generated by `scripts/generate-route-manifest.mjs`; sitemap uses it.
- 21 route bodies are captured markup in `replica/` (formatted/linted, componentized where
  uniform). 14 guide details use `pages/guide-page.tsx` (≤0.27% static diff), four compare details
  use `pages/compare-page.tsx` (≤0.2%), and five playbook details use `pages/playbook-page.tsx`
  (0%).
- Shared components: `ui/tano-button.tsx` (99), `ui/faq-row.tsx` (88), `media/reel-card.tsx` (235).
- All internal links use `next/link`; the custom client-nav interceptor is gone.
- CSS: purged design-system stylesheet + `runtime.css` for Lenis/inline-SVG-only classes.
- No-JS reveal fallback lives in `reveal.css` (`@media (scripting: none)`).
- Evidence: heavy captures are local-only; see `docs/EVIDENCE.md`.
